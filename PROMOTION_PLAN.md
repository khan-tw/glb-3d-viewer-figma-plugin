# Promotion Plan

## Audience and promise

For Figma designers who already have GLB assets and need product visuals for
presentations, mockups, and layout exploration. Turn a local GLB into a rendered
image in a Figma frame, with control over angle, lighting, and materials.

## Deliverables and acceptance

- Improve first use: included original sample, direct frame creation, accurate
  sync feedback. Verify inside Figma, including the resulting image fill.
- Publish version 1.1.0 to the EXISTING Community plugin
  `1689584566677007084`; verify the public page and the installed plugin.
- Replace the abstract cover with real rendered output, add comparison and
  quick-start images, and publish scannable use-case copy and relevant tags.
- Create a 20-30 second actual workflow video, with output shown first, then
  import/sample, adjustment, and synchronization. Do not simulate Figma success.
- Provide an MIT-licensed sample pack and a usable Figma playground with
  instructions and multiple example frames; verify access before sharing.
- Prepare English and Traditional Chinese social posts, using the same demo.
  Record posted URLs for any authorized publication; drafts are not outreach.
- Submit the open source plugin to Figma's community-resources repository after
  checking its current contribution requirements; record the request URL.

## Measurement

Baseline observed on October 23, 2026: the public Community page displayed
5 users. This is the platform's displayed count, not verified active usage.
Track Community count, comments, GitHub issues, and feedback from voluntary
testers. Do not add analytics or collect model data to measure promotion.

First qualitative target: 5-10 target users can import/sample, adjust, and sync
without assistance. Record their actual friction and repeat-use intent; do not
infer conversion from GitHub stars or views.

## Rollout order

1. Verify and release the onboarding fixes and refreshed listing.
2. Finish the sample playground and short workflow video.
3. Share a concrete use case on personal social accounts and permitted design
   communities. Keep posts specific and answer relevant questions.
4. Use observed feedback to prioritize the next plugin improvement.
