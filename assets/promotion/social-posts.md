## English: design / Blender communities

I built a small Figma plugin for a specific handoff: you have a GLB model, but
need a product visual in your Figma presentation or layout.

GLB 3D Frame Preview lets you import the model, adjust the angle and lighting,
and sync the view into a frame. It includes an original sample model, so you
can try the workflow without finding a file first.

It is free and open source. The plugin needs no account or API key and makes
no external network requests. The result in Figma is a PNG image fill, not an
interactive 3D object. Syncing replaces that frame's existing fills.

Try it: https://www.figma.com/community/plugin/1689584566677007084
Source and sample: https://github.com/khan-tw/glb-3d-viewer-figma-plugin

If you work with product renders or Blender assets, I would like to hear where
this fits your workflow, or what makes the first import difficult.
