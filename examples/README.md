# Studio Headphones Sample

An original, unbranded model made for GLB 3D Frame Preview. Created procedurally
with `scripts/create-sample.mjs`; no third-party models or textures are included.
The model and generator are available under this repository's MIT license.

[Open the Figma playground](https://www.figma.com/design/CxW8FvI0JErG3TNxrc3YGm/GLB-3D-Frame-Preview---Playground?node-id=1-5)
and duplicate it into your drafts. It includes editable instructions, three
real rendering examples, and an empty frame for your own experiments.

1. Run [GLB 3D Frame Preview](https://www.figma.com/community/plugin/1689584566677007084).
2. Choose **Try sample model**, or import `studio-headphones.glb`.
3. Choose **Create New Frame** if you do not already have a target frame.
4. Drag to rotate, adjust the lighting, then choose **Sync Frame**.

Try the Light background for product presentations, Transparent for compositing
(called Empty in version 1.1), or Clay to evaluate the shape. The canvas
receives a PNG image fill, not an interactive 3D layer.

In version 1.2, find backgrounds and materials under **Look**, angle
and size under **Position**, lighting under **Light**, and settings export under
**More**. Live sync is optional and off by default. Manual
**Sync Frame** replaces the selected target's fills, so use a dedicated frame.
